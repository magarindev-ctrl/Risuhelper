# RisuHelper 실모델 평가 기준선 (Eval Baselines)

이 디렉터리에는 [`tools/eval-real-model.mjs`](../../tools/eval-real-model.mjs) 또는 RisuAI 내장 임시 평가 플러그인(`dist/risuhelper-eval.js`)으로 실행한 **실제 모델 평가 리포트**를 마크다운 파일로 기록합니다.

## 측정 기준 (1.0.0 출시 조건)

- **종합 통과율 및 21개 내장 스킬 커버리지**: `v0.9.9` 기준 **71문항**(21개 내장 스킬 각각 최소 3문항: 정상 2+ · 거부/가드 1+, M0~M3 전 영역 및 3회 루프 3문항: 전문 조회 · L2 스킬 로드 · 자동 수정).
- **1회 호출 종료 비율**: 전체 시나리오의 **80% 이상**이 1회 호출로 완료 (`호출 루프 지표`에 자동 집계).
- **최대 호출 상한**: 어떤 시나리오에서도 `maxCallsObserved <= 3`.
- **프롬프트 크기 기준**: 시스템 프롬프트 평균이 `v0.5.1`(9,232자) 이하 유지.
- **거부(안전 가드) 시나리오**: 모든 모델에서 **100%**.

## 실행 명령 예시

```bash
# 1) CLI로 실행 (OpenAI / OpenRouter / Anthropic / Gemini)
OPENAI_API_KEY=... node tools/eval-real-model.mjs \
  --provider openai --model <model-id> --max-calls 3 --runs 3 \
  --out docs/eval-baselines/v0.9.9-<model>-calls3.md

# 2) RisuAI 앱 내부에서 실행 (API 키 별도 입력 불필요)
# dist/risuhelper-eval.js 설치 → ☰ 메뉴 "RisuHelper 71문항 평가" →
# 호출 상한 "최대 3회 (기본)" 실행 후 마크다운 리포트 복사·저장
```
